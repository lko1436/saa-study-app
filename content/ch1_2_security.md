# 👮 1-2 網路安全：誰能連上你的伺服器？

在 AWS 的網路世界裡，有兩層保全在擋人。一個管「家門」，一個管「社區大門」。

---

### 1. 安全組 (Security Group, SG) —— 【家門口的保全】
它是最常用到的安全設定。
* **特性：有記性 (Stateful)**
    * 只要是你主動找的人，他回來時，保全會直接讓他進門。
    * **重點：** 只要 Inbound（進入）規則開了，Outbound（出去）就自動會通。
* **限制：**
    * 只能設定「允許誰進來」，沒辦法設定「禁止誰進來」。
    * 它是針對每一台伺服器（EC2）單獨設定的。



---

### 2. 網路存取控制列表 (NACL) —— 【社區大門的警衛】
它是第二道防線，通常管一整群房間（子網路 Subnet）。
* **特性：沒記性 (Stateless)**
    * 進去要檢查一次，出來也要檢查一次。
    * 就算是你主動找的人，他要離開社區時，如果「出境名單」沒寫他的名字，他還是會被攔住。
* **優點：**
    * **可以設定黑名單 (Deny)**。如果你發現某個 IP 一直在攻擊你，你可以在這裡直接封鎖它。

---

### 📝 隨堂小測驗
**Q：如果你發現有一個壞人（IP: 1.2.3.4）一直嘗試破解你的密碼，你該去哪裡設定才能徹底擋住他？**

<details>
<summary><b>點擊查看答案</b></summary>
<b>答案：NACL</b>。<br>
因為只有 NACL 支援 <b>Deny (拒絕)</b> 規則，可以直接把特定的壞人 IP 丟進黑名單，安全組 (SG) 做不到這一點。
</details>

---

### ✍️ 筆記本重點摘要

1. **核心對比表：**
   | 功能 | Security Group (SG) | NACL |
   | :--- | :--- | :--- |
   | **保護對象** | 每一台伺服器 (EC2) | 整個房間 (Subnet) |
   | **記性 (State)** | **有 (Stateful)** | 無 (Stateless) |
   | **規則類型** | 僅支援 Allow (允許) | **支援 Allow 與 Deny (拒絕)** |

2. **必記關鍵字：**
   * **Stateful (SG)：** 單向設定，回程自動放行。
   * **Stateless (NACL)：** 雙向都要設定（Inbound & Outbound）。

3. **考試直覺：**
   * 看到「封鎖特定 IP (Deny)」 ➔ 選 **NACL**。
   * 看到「預設規則是拒絕所有流量」 ➔ **SG 與 NACL 都是**。
   * 看到「要針對 Subnet 層級控管」 ➔ 選 **NACL**。
