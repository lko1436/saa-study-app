# 🏰 1-1 打造你的雲端秘密基地 (VPC 基礎)

想像你在雲端租了一塊超大的空地，準備蓋一個秘密基地。這整塊地就叫 **VPC**。

---

### 1. VPC (你的秘密基地圍牆)
* **白話解釋：** 就是你基地最外面的那道**圍牆**。
* **為什麼要它：** 沒有這道牆，你的東西就隨便丟在路邊，誰都能看、誰都能拿。有了 VPC，這塊地就是你的私人領地。

---

### 2. Subnet (基地裡的小房間)
基地太大，我們要分房間，這就叫 **Subnet (子網路)**：
* **Public Subnet (對外開放的客廳)：** * 這房間有一扇大門叫 **Internet Gateway (網際網路閘道)**。
    * 外面的人可以從大門走進來參觀。
* **Private Subnet (藏寶的小黑屋)：** * 這房間**沒有門**通往外面。
    * 外面的人絕對進不去，非常安全。

---

### 3. NAT Gateway (秘密基地的傳聲筒)
住在「小黑屋」裡的人，有時候想聽外面的廣播或訂外送，但他不想開門怎麼辦？
* 他會用一個**傳聲筒 (NAT Gateway)** 向外面喊。
* **考試重點：** 傳聲筒一定要放在「有大門的客廳 (Public Subnet)」，外面的人才聽得到小黑屋的人在喊什麼。
* **效果：** 小黑屋的人可以對外面喊話，但外面的人沒辦法透過傳聲筒衝進去小黑屋。

---

### 4. IP 位址 (房間裡的座位表)
你想在房間放椅子給人坐，椅子就是 **IP 位址**。
* 如果你說這房間能放 16 張椅子。
* **AWS 規定：** 牆角、門後等 5 個位置我要留著放監視器跟電箱（**保留 IP**）。
* **結論：** 雖然有 16 個位子，但你實際只能坐 **11 個人** (16 - 5 = 11)。

---

### 📖 單字本 (中英對照)
| 專有名詞 | 秘密基地比喻 | 你要記得的重點 |
| :--- | :--- | :--- |
| **VPC** | 基地圍牆 | 這是你的私人空間。 |
| **Subnet** | 裡面的房間 | 分為「有大門的」跟「沒大門的」。 |
| **Internet Gateway (IGW)** | 基地大門 | 有了它，你的房間才能連到網路。 |
| **NAT Gateway** | 傳聲筒 | 讓沒門的房間能單向對外求救。 |

---

### 📝 秘密基地小測試
**Q：如果你想在基地蓋一個「超級保險庫」，連蒼蠅都飛不進去，但保險庫裡面的電腦需要偷偷上網更新軟體，你要準備哪兩樣東西？**

<details>
<summary><b>點擊看答案</b></summary>
<b>1. Private Subnet (小黑屋)</b>：把保險庫蓋在裡面，沒人進得去。<br>
<b>2. NAT Gateway (傳聲筒)</b>：讓裡面的電腦能向外喊話要更新。
</details>
