# 🏰 1-1 打造你的雲端秘密基地 (VPC 基礎)

想像你在雲端租了一塊超大的空地，準備蓋一個秘密基地。這整塊地就叫 **VPC**。

---

### 1. VPC (你的秘密基地圍牆)
* **白話解釋：** 就是你基地最外面的那道**圍牆**。
* **為什麼要它：** 沒有這道牆，你的東西就隨便丟在路邊。有了 VPC，這塊地就是你的私人領地。

---

### 2. Subnet (基地裡的小房間)
基地太大，我們要分房間，這就叫 **Subnet (子網路)**：
* **Public Subnet (對外開放的客廳)：** * 這房間有一扇大門叫 **Internet Gateway (IGW)**。
    * 外面的人可以從大門走進來參觀。
* **Private Subnet (藏寶的小黑屋)：** * 這房間**沒有門**通往外面。
    * 外面的人絕對進不去，非常安全。

---

### 3. NAT Gateway (秘密基地的傳聲筒)
住在「小黑屋」裡的人，有時候想聽外面的廣播或訂外送，但他不想開門怎麼辦？
* 他會用一個**傳聲筒 (NAT Gateway)** 向外面喊。
* **重點：** 傳聲筒一定要放在「有大門的客廳 (Public Subnet)」，外面的人才聽得到。
* **效果：** 小黑屋的人可以對外面喊話，但外面的人沒辦法透過傳聲筒衝進去。

---

### 4. IP 位址 (房間裡的座位表)
你想在房間放椅子給人坐，椅子就是 **IP 位址**。
* 如果你說這房間能放 16 張椅子。
* **AWS 規定：** 每個 Subnet 都會偷走 **5 個** 位置當作公投（監視器、電箱等）。
* **結論：** 16 - 5 = 你實際只能坐 **11 個人**。

---

### 📝 隨堂小測驗
**Q：如果你想在基地蓋一個「超級保險庫」，連蒼蠅都飛不進去，但保險庫裡面的電腦需要偷偷上網更新軟體，你要準備哪兩樣東西？**

<details>
<summary><b>點擊看答案</b></summary>
<b>1. Private Subnet (小黑屋)</b>：把保險庫蓋在裡面，沒人進得去。<br>
<b>2. NAT Gateway (傳聲筒)</b>：讓裡面的電腦能向外喊話要更新。
</details>

---

### ✍️ 筆記本重點摘要

1. **核心專有名詞：**
   * **VPC** = 秘密基地圍牆 (私人隔離空間)。
   * **Subnet** = 房間 (Public 有大門 / Private 沒大門)。
   * **IGW** = 大門 (讓基地連上 Internet)。
   * **NAT Gateway** = 傳聲筒 (讓 Private 區的人可以單向上網)。

2. **必記公式：**
   * **可用 IP = 總數 - 5** (AWS 固定的保留數量)。

3. **考試直覺：**
   * 需要絕對安全 (資料庫) ➔ **Private Subnet**。
   * 需要連通網路 ➔ **IGW**。
   * 私有區要上網抓東西 ➔ **NAT Gateway**。
