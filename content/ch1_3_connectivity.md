# 🌉 1-3 道路建設：如何把不同的基地連起來？

當你有兩個基地（VPC），或是想從公司辦公室連進雲端基地時，你需要蓋「路」。

---

### 1. 辦公室連到雲端：VPN 與 專線 (Direct Connect)
想像你要從辦公室搬東西到雲端基地，你有兩條路可以選：

* **VPN (走一般大馬路)：**
    * **白話解釋：** 就像騎機車走一般公用馬路。路是大家的，所以流量大時會塞車（網路不穩）。
    * **優點：** 很快就能蓋好，成本低。
* **Direct Connect / DX (專屬地下道)：**
    * **白話解釋：** 為了你特別挖一條專用的實體地下道，只有你能走。
    * **優點：** 絕對不會塞車，連線極度穩定。
    * **缺點：** 價格昂貴，且需要幾週時間施工。

---

### 2. 基地連基地：VPC Peering 與 Transit Gateway
如果你在雲端蓋了兩個不同的基地（VPC），想要互相搬東西：

* **VPC Peering (一對一天橋)：**
    * **白話解釋：** 在 A 基地跟 B 基地之間蓋一座天橋。
    * **限制：** 天橋不能轉彎。如果 A 連 B，B 連 C，A 是不能直接透過 B 去 C 的（這叫不支援傳遞性）。
* **Transit Gateway (中央轉運站)：**
    * **白話解釋：** 蓋一個超級轉運大站。所有基地都連到這台轉運站，大家想去哪就去哪，不用蓋一堆亂七八糟的天橋。



---

### 3. 不出門的秘密小道：VPC Endpoints
如果你在基地裡想去拿雲端其他的公共資源，但你不想走出基地大門、不想經過外面的公用馬路：

* **Gateway Endpoint (免費秘密小門)：** * **支援對象：** 只有 **S3** (雲端大倉庫) 與 **DynamoDB** (雲端筆記本)。
    * **特點：** **免費**。直接在基地圍牆上開個洞連過去。
* **Interface Endpoint (付費電梯)：** * **支援對象：** 除了上述兩個以外的大部分 AWS 服務。
    * **特點：** **要收錢**。像是在基地內蓋了一座付費電梯直達目的地。

---

### 📝 隨堂小測驗
**Q：如果你想從基地內存取 S3 (雲端大倉庫) 的資料，而且老闆規定「不能花錢」買連線，你該選哪一種？**

<details>
<summary><b>點擊查看答案</b></summary>
<b>答案：Gateway Endpoint</b>。<br>
因為它是專門給 S3 使用的免費秘密小門。

### ✍️ 筆記本重點摘要

1. **連線方式對比：**
   * **VPN：** 便宜快、走公網、不穩。
   * **Direct Connect (DX)：** 貴且慢、實體專線、極穩。

2. **多基地互連：**
   * **VPC Peering：** 一對一天橋，不能轉彎。
   * **Transit Gateway：** 大型轉運站，管理很多 VPC 的首選。

3. **秘密通道 (Endpoint)：**
   * **Gateway 型：** **免費** (僅限 S3 和 DynamoDB)。
   * **Interface 型：** **要錢** (其他服務用)。

4. **考試直覺：**
   * 看到「不走 Internet 抓 S3」+「省錢」 ➔ 選 **Gateway Endpoint**。
   * 看到「穩定大流量/專線」 ➔ 選 **Direct Connect**。
